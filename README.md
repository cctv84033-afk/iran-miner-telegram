# Iran Miner — نسخه آماده بارگذاری در GitHub و استقرار روی Render

> **هشدار ضروری:** این نرم‌افزار در وضعیت فعلی یک نمونه نمایشی است. استخراج واقعی، پرداخت بانکی یا انتقال رمزارز انجام نمی‌دهد. عبارت «واریز شد» نیز فقط وضعیت نمایشی پس از ۴۸ ساعت است و نباید به‌عنوان پرداخت واقعی معرفی شود.

## فایل‌ها

- `app.py`: بک‌اند Python با FastAPI و APIها
- `bot.py`: ربات تلگرام برای نمایش دکمه Mini App (اجرای جداگانه لازم دارد)
- `static/`: رابط وب و فایل ویدیوی ماینر
- `render.yaml`: تنظیمات ساخت و اجرای وب‌سرویس در Render
- `Procfile`: فرمان اجرای وب‌سرویس

## ۱. آپلود در GitHub

1. در GitHub یک repository جدید بسازید.
2. محتویات همین پوشه را در ریشه repository قرار دهید؛ یعنی `app.py` و `render.yaml` باید مستقیماً در صفحه اصلی repository دیده شوند.
3. پوشه `static` را نیز همراه فایل‌هایش آپلود کنید.
4. فایل `.env`، توکن ربات، فایل دیتابیس و اطلاعات کاربران را آپلود نکنید.

## ۲. انتشار لینک عمومی با Render

1. در Render ثبت‌نام کنید و حساب GitHub را متصل کنید.
2. از داشبورد Render گزینه **New → Blueprint** را انتخاب کنید.
3. repository پروژه را انتخاب کنید تا فایل `render.yaml` خوانده شود.
4. هنگام ساخت سرویس، مقدار محرمانه `BOT_TOKEN` را با توکن ربات BotFather تنظیم کنید. توکن را در GitHub یا کد قرار ندهید.
5. سرویس را Deploy کنید و منتظر پایان Build بمانید.
6. آدرس HTTPS ساخته‌شده در Render لینک عمومی سایت شماست.

سرویس رایگان Render ممکن است پس از مدتی بی‌فعالیتی به خواب برود و بازدید اول با تأخیر شروع شود.

### مهم درباره دیتابیس

این نسخه از SQLite استفاده می‌کند. فضای دیسک سرویس رایگان Render پایدار نیست؛ بنابراین داده‌های حساب‌ها و موجودی‌ها ممکن است بعد از Deploy یا راه‌اندازی مجدد از بین بروند. **برای استفاده عمومی با داده واقعی، قبل از انتشار باید دیتابیس PostgreSQL پایدار متصل و مهاجرت دیتابیس انجام شود.** این بسته برای انتشار و تست نمایشی است، نه نگهداری مطمئن حساب و موجودی واقعی.

## ۳. اتصال Mini App به تلگرام

1. پس از Deploy، آدرس HTTPS را در تنظیمات Mini App ربات در BotFather ثبت کنید.
2. همان توکن ربات را در Environment Variables سرویس Render با نام `BOT_TOKEN` وارد کنید.
3. `DEMO_MODE` باید `0` باشد. حالت دمو را روی سرویس عمومی فعال نکنید.

`bot.py` یک ربات polling است و توسط وب‌سرویس به‌صورت خودکار اجرا نمی‌شود. برای پاسخ‌گویی ربات و ارسال دکمه Web App باید آن را در یک worker/سرویس جداگانه اجرا کنید؛ یا از تنظیمات منوی Web App در BotFather استفاده کنید.

## ۴. قرار دادن ویدیوی ماینر

فایل ویدیوی ساخته‌شده را با نام دقیق `miner.mp4` داخل پوشه `static` قرار دهید:

```text
static/miner.mp4
```

در زمان استخراج، ویدیو loop و پخش می‌شود؛ با توقف یا پایان دوره، پخش متوقف می‌شود. اگر فایل وجود نداشته باشد یا قابل پخش نباشد، تصویر انیمیشنی جایگزین نمایش داده می‌شود.

پیشنهاد می‌شود ویدیو MP4 با کدک H.264 و حجم بهینه باشد. محدودیت حجم فایل GitHub را در نظر بگیرید؛ ویدیوی حجیم را بهتر است در فضای ذخیره‌سازی ویدیویی میزبانی کنید و آدرس آن را در `static/app.js` تنظیم کنید.

## ۵. تست محلی

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8000
```

سپس `http://127.0.0.1:8000` را باز کنید. برای تست محلی رابط می‌توان موقتاً `DEMO_MODE=1` تنظیم کرد؛ این حالت فقط برای تست محلی است و نباید روی سایت عمومی فعال شود.

## امنیت

- رمز تلگرام را درخواست یا ذخیره نکنید.
- توکن ربات را فقط در Environment Variables قرار دهید.
- پیش از هر استفاده عمومی، دیتابیس پایدار، پشتیبان‌گیری، محدودسازی درخواست‌ها و بازبینی امنیتی لازم است.
